A kind, funny fortune for a houseplant: it will outgrow its pot, then the sill, then the whole window — and its keeper will still call it his little plant.

The program writes exactly that one line (118 characters, no trailing newline) to `$MAKEFUN_OUTPUT_DIR/entry.txt`, inside the 1–120 character gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
